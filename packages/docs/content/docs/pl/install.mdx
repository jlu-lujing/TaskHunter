# Instalacja

Wybierz aplikację, która pasuje do twojego sposobu pracy:

- aplikacja na komputer dla macOS, Windows i Linuksa
- aplikacja webowa uruchamiana przez CLI, którą możesz zainstalować jak aplikację na telefonie (jako PWA)
- rozszerzenie do VS Code, także do Cursora, Windsurfa i Trae
- aplikacje mobilne na iPhone’a i Androida, w publicznej becie

## Komputer

Pobierz najnowszą wersję ze [strony pobierania](https://taskhunter.dev/download/) lub z [GitHub Releases](https://github.com/jlu-lujing/TaskHunter/releases/latest) i otwórz ją. Dla Linuksa są pakiety `.deb`, `.rpm` i AppImage.

Aplikacja na komputer ma własną kopię [OpenCode](https://opencode.ai) (agenta AI do kodu, na którym działa TaskHunter), więc nie trzeba niczego więcej instalować.

## Przeglądarka + PWA

Aplikacja webowa potrzebuje [OpenCode](https://opencode.ai) i Node.js w wersji 24.14 lub nowszej na maszynie, na której działa.

```bash
curl -fsSL https://raw.githubusercontent.com/jlu-lujing/TaskHunter/main/scripts/install.sh | bash
taskhunter --ui-password be-creative-here
```

Otwórz adres URL wypisany przez CLI (zwykle `http://localhost:3000`). Powinna pojawić się lista sesji TaskHunter. Żeby mieć ją pod ręką, użyj opcji „Zainstaluj” w pasku adresu przeglądarki i dodaj ją jako aplikację.

## VS Code

Zainstaluj TaskHunter z [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.taskhunter). Cursor, Windsurf i Trae instalują go z [Open VSX](https://open-vsx.org/extension/FedaykinDev/taskhunter). Rozszerzenie wymaga zainstalowanego [OpenCode](https://opencode.ai); potem widok TaskHunter otwiera się na pasku bocznym.

## Telefon

Zainstaluj aplikację na iPhone’a przez TestFlight albo aplikację na Androida z najnowszego wydania, a potem sparuj ją z komputerem. [Aplikacje mobilne i PWA](/pl/mobile/) opisuje oba kroki.
