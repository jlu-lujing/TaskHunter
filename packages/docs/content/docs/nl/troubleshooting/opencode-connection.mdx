# Verbinding met OpenCode

Als TaskHunter wel laadt maar blijft melden dat OpenCode opnieuw wordt gestart, of als de chat niet reageert, is de achterliggende server niet bereikbaar. Loop de volgende controles na.

## De melding over opnieuw starten blijft staan

- wacht direct na het openen even; tijdens het starten van de server is deze melding normaal
- controleer met `taskhunter status` of de server draait
- herstart met `taskhunter restart`
- bekijk de opstartdetails met `taskhunter logs`

## U gebruikt een eigen server

Als TaskHunter met een bestaande server moet verbinden, controleer dan de instellingen uit [OpenCode-server](/nl/opencode-server/):

- `OPENCODE_HOST` moet de poort bevatten en mag geen pad hebben, bijvoorbeeld `http://localhost:4096`
- stel `OPENCODE_SKIP_START=true` in, zodat TaskHunter niet ook zelf een server start
- bij een ongeldig adres negeert TaskHunter het en start het zelf een server; zoek in de logs naar een waarschuwing met `[config]`

## Het werkt nog steeds niet

- controleer of Node.js versie `24.14` of nieuwer is geïnstalleerd
- installeer de nieuwste CLI opnieuw
- open eerst rechtstreeks `http://localhost:3000` voordat u een tunnel- of remotelink probeert
