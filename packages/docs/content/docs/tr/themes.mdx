# Temalar

TaskHunter yerleşik temaları ve özel tema JSON dosyalarını destekler.

## Özel tema ekleme

1. Tema dizinini oluşturun:

```bash
mkdir -p ~/.config/taskhunter/themes
```

2. JSON dosyanızı bu dizine ekleyin, örneğin `my-theme.json`.
3. TaskHunter'ı açın, sonra **Settings -> Theme -> Reload themes** yoluna gidin.
4. Temanızı açılır menüden seçin. Hemen uygulanır.

## Tema konumu

- macOS/Linux: `~/.config/taskhunter/themes/`
