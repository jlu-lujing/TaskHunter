# Install

There are three ways to run TaskHunter:

- desktop app for macOS
- web app hosted by the CLI, which you can install like a phone app (a PWA)
- VS Code extension

## Prerequisite

Install [OpenCode](https://opencode.ai) first — TaskHunter runs on top of it.

## Web + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jlu-lujing/TaskHunter/main/scripts/install.sh | bash
taskhunter --ui-password be-creative-here
```

Open the URL the CLI prints (usually `http://localhost:3000`). You should see the TaskHunter session list. To keep it handy, use your browser's "Install" option in the address bar to add it as an app.

## Desktop

Download the latest desktop build from the GitHub releases page or the TaskHunter download page. Open it and sign into your usual OpenCode workflow.

## VS Code

Install from the VS Code Marketplace and sign into your usual OpenCode workflow. The TaskHunter view then opens in the sidebar.
