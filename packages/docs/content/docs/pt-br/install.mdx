# Instalação

Escolha o app que combina com o seu jeito de trabalhar:

- app de desktop para macOS, Windows e Linux
- app web executado pela CLI, que você pode instalar como um app de celular (um PWA)
- extensão para VS Code, também para Cursor, Windsurf e Trae
- apps móveis para iPhone e Android, em beta pública

## Desktop

Baixe a versão mais recente na [página de download](https://taskhunter.dev/download/) ou no [GitHub Releases](https://github.com/jlu-lujing/TaskHunter/releases/latest) e abra. Para Linux há `.deb`, `.rpm` e AppImage.

O app de desktop traz a própria cópia do [OpenCode](https://opencode.ai) (o agente de IA para código em que o TaskHunter roda), então não há mais nada para instalar.

## Web + PWA

O app web precisa do [OpenCode](https://opencode.ai) e do Node.js 24.14 ou mais recente na máquina onde ele roda.

```bash
curl -fsSL https://raw.githubusercontent.com/jlu-lujing/TaskHunter/main/scripts/install.sh | bash
taskhunter --ui-password be-creative-here
```

Abra a URL que a CLI mostra (normalmente `http://localhost:3000`). Você deve ver a lista de sessões do TaskHunter. Para deixá-lo à mão, use a opção "Instalar" na barra de endereço do navegador e adicione-o como app.

## VS Code

Instale o TaskHunter pelo [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.taskhunter). Cursor, Windsurf e Trae instalam pelo [Open VSX](https://open-vsx.org/extension/FedaykinDev/taskhunter). A extensão precisa do [OpenCode](https://opencode.ai) instalado; depois, a visualização do TaskHunter abre na barra lateral.

## Celular

Instale o app de iPhone pelo TestFlight ou o app de Android pela versão mais recente e depois pareie-o com o seu computador. [Apps Móveis e PWA](/pt-br/mobile/) mostra os dois passos.
