# Ferramenta de controle para agentes

Use a ferramenta de agente `taskhunter` para gerenciar o trabalho no aplicativo diretamente pelo chat. Ela vem ativada por padrão quando o TaskHunter executa seu próprio servidor OpenCode local; não é preciso instalar outra ferramenta nem executar um comando de shell.

## O que você pode pedir

Peça ao agente em linguagem natural. Por exemplo:

- “Crie uma nova sessão do TaskHunter neste projeto, use o modelo `openai/gpt-5.6-sol` e envie este prompt: revise o fluxo de autenticação.”
- “Crie uma nova sessão do TaskHunter para esta tarefa em um worktree separado e peça para ela adicionar testes ao fluxo de login.”
- “Use o TaskHunter para listar minhas 10 sessões mais recentes e inclua o status atual delas.”
- “Crie no TaskHunter uma tarefa agendada chamada Revisão dos dias úteis que envie este prompt às 09:00 de cada dia útil: revise as alterações desde a última execução.”
- “Execute agora a tarefa agendada do TaskHunter chamada Revisão dos dias úteis.”
- “Verifique a sessão do TaskHunter chamada Revisão de autenticação e mostre a resposta mais recente do assistente.”

A ferramenta pode listar projetos e preferências de modelos, criar e continuar sessões, bifurcar uma sessão, criar sessões em worktrees isolados e gerenciar tarefas agendadas. As sessões iniciadas assim aparecem no TaskHunter como qualquer outra, então você pode abri-las e continuar o trabalho por conta própria.

## Lembre-se

- Os prompts de novas sessões retornam imediatamente por padrão. Acompanhe a sessão no TaskHunter ou peça ao agente para verificá-la mais tarde.
- Um worktree separado só é criado quando você pede. As alterações não commitadas do worktree atual não são copiadas.
- A ferramenta não pode excluir sessões ou worktrees, registrar caminhos de projetos, executar comandos de shell arbitrários nem acessar URLs arbitrárias.

## Ativar ou desativar a ferramenta

Abra **Configurações → Geral → Ferramentas do TaskHunter** e altere **Ferramenta de controle para agentes**. A configuração entra em vigor quando o servidor OpenCode gerenciado reinicia, o que o TaskHunter oferece como **Apply & Restart**.

A ferramenta não está disponível quando o TaskHunter se conecta a um servidor OpenCode externo por `OPENCODE_HOST` ou skip-start, nem na extensão do VS Code. As instalações desktop e web que usam o servidor OpenCode gerenciado pelo TaskHunter têm suporte automático.
