# Installieren

Es gibt drei Möglichkeiten, TaskHunter auszuführen:

- Desktop-App für macOS
- Web-App, die vom CLI gehostet wird und die du wie eine Handy-App installieren kannst (eine PWA)
- VS-Code-Erweiterung

## Voraussetzung

Installiere zuerst [OpenCode](https://opencode.ai) — TaskHunter läuft darauf auf.

## Web + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jlu-lujing/TaskHunter/main/scripts/install.sh | bash
taskhunter --ui-password be-creative-here
```

Öffne die URL, die das CLI ausgibt (normalerweise `http://localhost:3000`). Du solltest die TaskHunter-Session-Liste sehen. Damit du sie griffbereit hast, kannst du im Adressfeld deines Browsers über die Option „Installieren“ daraus eine App machen.

## Desktop

Lade den aktuellen Desktop-Build von der GitHub-Releases-Seite oder der TaskHunter-Downloadseite herunter. Öffne ihn und melde dich in deinem gewohnten OpenCode-Workflow an.

## VS Code

Installiere sie aus dem VS Code Marketplace und melde dich in deinem gewohnten OpenCode-Workflow an. Die TaskHunter-Ansicht öffnet sich dann in der Seitenleiste.
